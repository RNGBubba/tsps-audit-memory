## Simple workflow

1. Pick **one** item family or audit slice.
2. Map the active TS ID and runtime row.
3. Compare its exact authoritative DB key.
4. Trace runtime load/use/enforcement.
5. Search existing IDs/titles/root causes.
6. Log **match**, **candidate**, or **verified new finding** accurately.
7. Keep all changes inside `Memory/`.
